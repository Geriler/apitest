# Макетка

3D-песочница электрических цепей в браузере: макетная плата на 400 точек, батареи, резисторы, конденсаторы, диоды, светодиоды, лампы накаливания, тумблеры и провода (цвет можно выбрать). Токи считаются по законам Ома и Кирхгофа, конденсаторы заряжаются и разряжаются во времени, детали перегреваются и выходят из строя при превышении номинала.

Полярные детали (диод, светодиод, электролитический конденсатор) ставятся так: первое отверстие — анод / плюс, второе — катод / минус. Клавиша F переворачивает выбранную деталь.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты решателя и модели
npm run build      # сборка в dist/
npm run smoke -- --chrome /path/to/chrome   # проверка в настоящем браузере (после build)
npm run artifact   # один HTML-файл в dist-artifact/ для публикации
```

## Как устроено

| Папка | Что там |
|---|---|
| `src/sim/solver.ts` | Решатель постоянного тока методом узловых потенциалов. Батарея — ЭДС с внутренним сопротивлением (эквивалент Нортона), поэтому короткое замыкание не делает систему вырожденной. |
| `src/sim/simulation.ts` | Схема из деталей на плате → ветви для решателя. Конденсаторы — неявный метод Эйлера с шагом 5 мс; диоды — уравнение Шокли, итерации Ньютона с ограничением шага (как pnjlim в SPICE); перегрев и выход из строя. |
| `src/sim/resistorCodes.ts` | Ряд E12, цветные полосы, код SMD. |
| `src/model/` | Топология макетки (полосы a–e / f–j, шины ±) и типы деталей. Без Three.js. |
| `src/view/` | Three.js: модели деталей в реальном масштабе (1 ед. = шаг 2,54 мм), плата, свечение, дым, точки тока. |
| `src/app.ts` | Инструменты, установка деталей, провода, панель показаний. |

## Упрощения

- Нет катушек индуктивности и транзисторов. Пробой диодов в обратном направлении не моделируется.
- Параметры светодиодов подобраны по типовому прямому напряжению при 20 мА; у реальных светодиодов разброс.
- Сопротивление лампы постоянное (горячая нить). У настоящей лампы холодная нить в ~10 раз «легче», поэтому бросок тока при включении не моделируется.
- Перегрев — игровая модель: тепло копится, пока мощность выше порога (резистор — 100 % номинала, лампа — 130 %).
- SMD-резисторы есть в модели, но скрыты из интерфейса до появления печатной платы.
