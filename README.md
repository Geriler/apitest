# Макетка

3D-песочница электрических цепей в браузере: макетная плата на 400 точек, печатная плата с медными дорожками, лабораторный блок питания, батареи, резисторы, конденсаторы, диоды, светодиоды, транзисторы BC547/BC557, полевые транзисторы 2N7000/IRLZ44N/IRF9540N, лампы накаливания, тумблеры и провода (цвет можно выбрать). Токи считаются по законам Ома и Кирхгофа, конденсаторы заряжаются и разряжаются во времени, детали перегреваются и выходят из строя при превышении номинала.

Полярные детали (диод, светодиод, электролитический конденсатор) ставятся так: первое отверстие — анод / плюс, второе — катод / минус. Клавиша F переворачивает выбранную деталь. Транзистор ставится одним щелчком в три соседних столбца: коллектор, база, эмиттер. MOSFET — так же, в порядке ножек своего корпуса (2N7000: исток, затвор, сток; TO-220: затвор, сток, исток).

Печатная плата лежит перед макеткой: 24 × 14 площадок, изначально ни с чем не соединённых. Инструмент «Дорожка» (T) рисует медь от площадки к площадке; дорожка, прошедшая по площадке, с ней соединяется. Сопротивление дорожки — по длине (медь 35 мкм × 1,8 мм — ширина площадки — ≈ 0,27 мОм/мм), провода — тоже по длине (22 AWG ≈ 53 мОм/м). Провод бывает двух видов, выбор — в панели инструмента «Провод» (и у готового провода — в его панели): **прямая перемычка** лежит на плате, концы загнуты в отверстия (только если оба конца на одной плате), **гибкий** идёт дугой и дотянется куда угодно — к детали на столе или на другую плату.

Номинал выбирается у каждой детали — перед установкой и потом в её панели: резистор 0,125 / 0,25 / 0,5 / 1 / 2 Вт (чем мощнее, тем крупнее корпус), конденсатор — номинальное напряжение (электролит 6,3–63 В, банка растёт с напряжением; керамика 16 / 50 / 100 В), диод 1N4148 (0,2 А, стекло) / 1N4007 (1 А) / 1N5408 (3 А), светодиод 5 мм на 20 мА или мощный на 1 Вт (350 мА). От номинала зависит, когда деталь перегреется. У ламп, батарей, транзисторов и MOSFET номинал задаётся моделью. Старые схемы открываются с прежними номиналами.

Отмена: Ctrl+Z (или ↶ вверху) отменяет последнее действие, Ctrl+Y / Ctrl+Shift+Z (↷) возвращает — до 100 шагов, включая «Очистить» и загрузку примера. Обычное нажатие на деталь, провод или дорожку выделяет её (Del — удалить, R — повернуть, F — перевернуть), тумблер от нажатия переключается; **Shift+нажатие** (на телефоне — долгое нажатие) открывает панель с показаниями и настройками. Детали можно перетаскивать мышью и на столе, и по плате: выводы переезжают в соседние отверстия той же формы, можно и на другую плату; в занятые отверстия деталь не встанет.

Интерфейс: инструменты слева собраны в группы (соединения, платы, пассивные, полупроводники, лампа и тумблер, питание) — щелчок по группе раскрывает её; горячие клавиши работают как раньше. Допуски, показ тока и замена сгоревших — в меню «Настройки». Сводка по схеме и подсказки справа — по кнопке «?».

Проекты (кнопка «Проекты»): сохранить схему под именем в этом браузере, открыть или удалить сохранённую, скачать проект файлом .json и открыть такой файл (например, в другом браузере). Открытие проекта отменяется Ctrl+Z.

Принципиальная схема (кнопка «Схема»): строится по сборке сама. Всё, что соединено (полосы макетки, провода, дорожки), — одна цепь, горизонтальная линия; цепи идут сверху вниз по убыванию потенциала (подписан у каждой), детали стоят вертикально между своими цепями, обозначения — по ЕСКД, рядом имя, номинал и ток. Точка на пересечении — соединение, без точки — нет. Щелчок по детали на схеме открывает её панель, тумблер переключается. «100 %» — натуральная величина с прокруткой, иначе схема вписана в панель. Для больших схем раскладка простая и может быть запутанной — это не чертёж, нарисованный человеком.

Лабораторный блок питания (P): 0–30 В, ограничение тока 0–3 А. Держит напряжение (CV), пока ток меньше ограничения, иначе держит ток (CC) — короткое замыкание ему не страшно.

Платы — такие же предметы на столе, как детали. Инструменты «Макетка» (B) и «Печатная плата» (V) кладут новую плату на свободное место; размер печатной (24 × 14, 36 × 20 или 48 × 26 площадок) выбирается перед установкой и меняется потом в панели платы. Щелчок по плате выбирает её (обводится рамкой) — выбранную можно тащить мышью, детали, провода и дорожки едут вместе с ней; невыбранная не мешает вращать камеру. Платы не налезают друг на друга и на детали на столе. Убрать плату — инструментом «Удалить», клавишей Del или кнопкой в панели, но только пустую: иначе песочница назовёт, что на ней стоит. Макетки между собой не соединены, как настоящие — шины соединяют проводом; дорожка с платы на плату не переходит. Платы сохраняются со схемой (старые сохранения с раскладкой открываются как были); «Очистить» оставляет совсем пустой стол — без деталей, проводов, дорожек и плат. Кнопка «Ток» прячет бегущие точки тока (расчёт и показания не меняются).

Кнопка «Допуски» включает разброс параметров, как у настоящих деталей: резисторы ±5 %, электролиты ±20 %, керамика ±10 %, лампы ±10 %, прямое напряжение светодиодов ±0,15 В, β транзисторов 200–450, порог MOSFET по даташиту (2N7000 0,8–3 В, IRLZ44N 1–2 В, IRF9540N 2–4 В), батареи ±3 % по ЭДС и ±40 % по внутреннему сопротивлению. Отклонение у каждой детали постоянное (зависит от её обозначения), «Другие экземпляры» выбирает новые.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты решателя и модели
npm run build      # сборка в dist/
npm run smoke -- --chrome /path/to/chrome   # проверка в настоящем браузере (после build)
npm run artifact   # один HTML-файл в dist-artifact/ для публикации
```

## Как устроено

| Папка | Что там |
|---|---|
| `src/sim/solver.ts` | Решатель методом узловых потенциалов. Батарея — ЭДС с внутренним сопротивлением (эквивалент Нортона), поэтому короткое замыкание не делает систему вырожденной. Есть источники тока и источники тока, управляемые напряжением (для транзистора). |
| `src/sim/simulation.ts` | Схема из деталей на плате → ветви для решателя. Конденсаторы — неявный метод Эйлера с шагом 5 мс; диоды — уравнение Шокли, итерации Ньютона с ограничением шага (как pnjlim в SPICE); транзисторы — модель Эберса–Молла; MOSFET — квадратичная модель канала с плавным подпороговым участком, паразитный диод, ёмкости затвора; если Ньютон не сошёлся, шаг дробится пополам (до ≈ 150 нс); перегрев и выход из строя. |
| `src/sim/resistorCodes.ts` | Ряд E12, цветные полосы, код SMD. |
| `src/sim/tolerance.ts` | Режим допусков: повторяемые отклонения по детали и параметру. |
| `src/model/` | Топология макетки (полосы a–e / f–j, шины ±) и типы деталей. Без Three.js. |
| `src/view/` | Three.js: модели деталей в реальном масштабе (1 ед. = шаг 2,54 мм), плата, свечение, дым, точки тока. |
| `src/app.ts` | Инструменты, установка деталей, провода, панель показаний. |

## Упрощения

- Нет катушек индуктивности. Пробой p-n переходов в обратном направлении не моделируется.
- Ёмкость переходов транзистора завышена до 10 нФ (у настоящего BC547 — пикофарады): без неё у схем с положительной обратной связью нет непрерывного решения в момент переключения. Переключение занимает микросекунды — для глаза мгновенно. Нет эффекта Эрли, β не зависит от тока. Ёмкости затвора MOSFET тоже завышены (10 нФ затвор–исток, 1 нФ затвор–сток), нет модуляции длины канала и зависимости порога от температуры.
- Параметры светодиодов подобраны по типовому прямому напряжению при номинальном токе (20 мА, у мощного 350 мА); у реальных светодиодов разброс. Модель 1N5408 подобрана по паспортным точкам, а не взята у производителя.
- Сопротивление лампы постоянное (горячая нить). У настоящей лампы холодная нить в ~10 раз «легче», поэтому бросок тока при включении не моделируется.
- Перегрев — игровая модель: тепло копится, пока мощность выше порога (резистор — 100 % номинала, лампа — 130 %).
- SMD-резисторы есть в модели, но скрыты из интерфейса до появления печатной платы.
